# Norm Scoop Bucket

Install the Norm command-line toolchain on Windows x64:

```powershell
scoop bucket add normlanguage https://github.com/normlanguage/scoop-bucket
scoop install normlanguage/normlang
norm --version
```

Update with `scoop update normlang` and remove with `scoop uninstall normlang`.

The manifest is generated by the [Norm release pipeline](https://github.com/normlanguage/Norm/blob/main/docs/en/design/release-process.md).
