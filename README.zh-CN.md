# Norm Scoop Bucket

[English](README.md)

在 Windows x64 上安装 Norm 命令行工具链：

```powershell
scoop bucket add normlanguage https://github.com/normlanguage/scoop-bucket
scoop install normlanguage/normlang
norm --version
```

使用 `scoop update normlang` 更新，使用 `scoop uninstall normlang` 卸载。

清单由 [Norm 发布流程](https://github.com/normlanguage/Norm/blob/main/docs/zh/design/release-process.md)生成。
